🔑 Cấu Hình Google API Trước Khi Dùng

Các bước tạo miễn phí trên Google Cloud:
  1. Vào Google Cloud Console, tạo Project mới.
  2. Mở mục APIs & Services $\rightarrow$ Library, bật Google Drive API.
  3. Vào Credentials $\rightarrow$ Create Credentials $\rightarrow$ OAuth client ID.
  4. Chọn Web application, tại Authorized JavaScript origins thêm link web GitHub của bạn (hoặc http://localhost).
  5. Copy Client ID và API Key dán vào ô bên dưới.
Vui lòng nhập đầy đủ cả Client ID và API Key hợp lệ!
